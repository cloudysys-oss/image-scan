規則:
1. 只回報實際的填寫欄位（有標籤且有對應填寫區域者）。純標題、說明文字、頁碼、表格框線不算欄位。
2. field_name 請使用該欄位在表單上的標籤原文。若同一標籤出現多次，在後面加上序號，例如「金額_2」。

僅輸出 JSON，不要輸出任何說明文字或 markdown 標記：

{
  "fields": [
    {
      "field_name": "申請人姓名",
      "value": "王小明",

    }
